## 💻 Sobre o Projeto

O **StudySync** é uma aplicação web que simula a experiência de aprendizado gamificado. O sistema gerencia cursos, unidades e lições através de um backend robusto e oferece uma experiência de usuário fluida e responsiva no frontend.

### ✨ Funcionalidades Principais
- **Trilha de Aprendizado:** Visualização de unidades e lições em formato de mapa interativo.
- **Sistema de Lições:** Exercícios de múltipla escolha com validação em tempo real.
- **Feedback Visual:** Interface reage (Verde/Vermelho) dependendo da resposta do usuário.
- **API RESTful:** Backend estruturado servindo dados em JSON para o frontend.

---

## 🛠️ Tecnologias Utilizadas

### Backend (API)
- **Java & Spring Boot:** Núcleo da aplicação.
- **Spring Data JPA:** Para persistência de dados.
- **H2 Database:** Banco de dados em memória (para desenvolvimento rápido).
- **Lombok:** Para redução de código boilerplate.

### Frontend (Interface)
- **React.js:** Biblioteca para construção da interface.
- **Vite:** Build tool para performance extrema.
- **Tailwind CSS:** Estilização moderna e responsiva.
- **Fetch API:** Para comunicação com o Backend.
